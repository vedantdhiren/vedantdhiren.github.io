Odyssey Bot is a feature-rich, asynchronous Discord economy bot designed to provide advanced financial and investment systems for server communities. The application features a robust multi-tiered banking layout, portfolio short-selling logic, active market tracking, and virtual real estate systems. Backed by automated 30-minute database backup operations, the application prevents data corruption automatically while keeping terminal logging optimized and quiet.

ECONOMY & TRANSACTION COMMANDS

  • /balance — View your wallet balance, bank deposits, and overall net worth.
  • /market — View the global marketplace dashboard and live asset pricing.
  • /buy_stock — Buy equity shares using your available wallet funds.
  • /sell_stock — Sell your portfolio equity shares for immediate cash.
  • /short_stock — Open a short stock position with a 150% margin requirement.
  • ?sync — Admin command to manually synchronize application commands with Discord.
